# Finance Manager Frontend

A modern Personal Finance Manager frontend built using React + Vite + Tailwind CSS.

---

# Features

- Beautiful Modern UI
- JWT Authentication
- Dashboard Analytics
- Transaction Management
- Category Management
- Goal Tracking
- Financial Reports
- Responsive Design
- Protected Routes

---

# Tech Stack

- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM
- Recharts


# Run Locally

## Clone

```bash
git clone YOUR_FRONTEND_REPO_LINK
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

---

# Build Production

```bash
npm run build
```
